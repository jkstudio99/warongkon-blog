Anthropic ระบุใน [release notes วันที่ 6 พฤศจิกายน 2026](https://support.claude.com/en/articles/12138966-release-notes) ว่าองค์กร Claude Enterprise ที่เข้าเงื่อนไขเริ่มใช้ project tags รุ่นเบต้าได้แล้ว เพื่อผูกค่าใช้จ่ายกับรหัสที่บริษัทใช้อยู่ เช่น รหัสโครงการหรือรหัสงานลูกค้า ข่าว Global / AI รอบวันที่ 7 พฤศจิกายนนี้จึงเกี่ยวกับการจัดการต้นทุนการใช้ AI ในองค์กร

## ติดตามค่าใช้จ่ายตามโครงการ

ตาม [คู่มือของ Claude](https://support.claude.com/en/articles/18251257-track-spend-by-cost-code-with-project-tags) เจ้าขององค์กรสร้างหมวดแท็กและค่าที่ใช้ได้ จากนั้นผู้มีสิทธิ์แก้ไขโครงการเลือกค่าให้โครงการนั้นได้ องค์กรดูรายงานแยกตามแท็กผ่านหน้าตั้งค่าหรือ API ได้ งานที่อยู่นอกโครงการจะไม่ได้รับแท็ก

ตัวเลขในรายงานมีเงื่อนไขที่ต้องเข้าใจก่อนนำไปใช้ แท็กไม่ได้ย้อนกลับไปจัดหมวดค่าใช้จ่ายเก่าก่อนเริ่มมีผล และรายงานอาจไม่ตรงกับยอดใบแจ้งหนี้ ฟีเจอร์นี้จึงเหมาะกับการมองการกระจายต้นทุนภายใน มากกว่าถือเป็นยอดเรียกเก็บสุดท้าย

เบต้ายังไม่รองรับองค์กรบางรูปแบบ รวมถึงองค์กรที่จัดเก็บข้อมูลนอกสหรัฐฯ ใช้ ZDR หรือใช้กุญแจเข้ารหัสที่ลูกค้าจัดการเอง ผู้ดูแลควรตรวจสิทธิ์องค์กรก่อนวางกระบวนการรายงานค่าใช้จ่ายรอบใหม่

ภาพปกใช้ [ภาพ Claude Support จากหน้าเอกสารทางการ](https://downloads.intercomcdn.com/i/o/lupk8zyo/792494/717b10d3ebd874823db64841659b/76f3062d78ebbb04863fb1de3ef9cca0.png) เป็นภาพทดแทน เนื่องจากไม่พบภาพหน้าจอ project tags ที่เหมาะเป็นปกในรอบนี้ ไม่ใช่ภาพหน้าจอฟีเจอร์
