ข่าว **Hardware / Infrastructure** สำหรับรอบวันที่ **28 สิงหาคม 2026** คือการที่ **Kioxia** และ **Sandisk** ประกาศแผนลงทุนรวมมากกว่า **31 พันล้านดอลลาร์สหรัฐ** หรือประมาณ **5 ล้านล้านเยน** ในญี่ปุ่นจนถึงปี 2032 เพื่อขยายเทคโนโลยีและกำลังผลิต flash memory

Kioxia เผยแพร่ข่าวเมื่อวันที่ **27 สิงหาคม 2026** จากโตเกียวและมิลพิตัส โดยระบุว่าแผนลงทุนยังขึ้นกับการสนับสนุนจากรัฐบาลญี่ปุ่น ขณะเดียวกัน Reuters รายงานผ่าน Channel NewsAsia ในวันที่ 27 สิงหาคมว่าแผนนี้เกิดขึ้นท่ามกลาง demand memory ที่ถูกเร่งโดย AI boom และมีการพบปะระหว่างผู้บริหาร Kioxia, Sandisk และนายกรัฐมนตรีญี่ปุ่นในวันเดียวกัน

นี่เป็นข่าว infrastructure เพราะ AI ไม่ได้ติดคอขวดที่ GPU เท่านั้น แต่กำลังติดตั้งแต่ memory, storage, power, network, fab capacity และ capital cycle ที่ยาวหลายปี

## ทำไม NAND flash สำคัญในยุค AI

เวลาพูดถึง AI infrastructure ตลาดมักนึกถึง GPU, HBM, data center และพลังงานก่อน แต่ NAND flash และ SSD เป็นชั้นที่ทำให้ระบบเก็บ อ่าน และเคลื่อนย้ายข้อมูลจำนวนมหาศาลได้ต่อเนื่อง

AI workload ต้องใช้ storage หลายรูปแบบ:

- training dataset ขนาดใหญ่
- checkpoint ของ model หลายเวอร์ชัน
- synthetic data และ evaluation data
- vector database และ retrieval store
- log จาก agent และ workflow องค์กร
- multimodal asset เช่น video, audio, image และ simulation output
- cold และ warm storage สำหรับ compliance และ audit

เมื่อ AI ขยับจาก chatbot ไปสู่ agentic AI, physical AI และ on-device AI ปริมาณข้อมูลไม่ได้โตเป็นเส้นตรง แต่โตตามจำนวน task, sensor, experiment และ interaction ที่ระบบต้องเก็บไว้

## ตัวเลขใหญ่กว่า capex ปกติ

Kioxia และ Sandisk ระบุว่า partnership ของทั้งสองบริษัทลงทุนในญี่ปุ่นไปแล้วมากกว่า **50 พันล้านดอลลาร์** ในช่วง 25 ปีที่ผ่านมา แผนใหม่มากกว่า 31 พันล้านดอลลาร์จึงไม่ใช่การเพิ่มงบเล็ก ๆ แต่เป็นการวางรอบลงทุนใหม่ให้ทัน demand กลางทศวรรษหน้า

จุดสำคัญของประกาศคือ:

- ลงทุนในญี่ปุ่นจนถึงปี **2032**
- รวม infrastructure, technology และ production capacity
- สนับสนุนโรงงาน **Yokkaichi Plant** และ **Kitakami Plant**
- ตั้งเป้าเพิ่ม bit growth หลายปี
- เน้น stable supply ของ flash memory รุ่นใหม่
- อยู่ภายใต้เงื่อนไขการสนับสนุนจากรัฐบาล

ข่าวนี้ต้องอ่านคู่กับการที่ผู้ผลิต memory รายอื่นเพิ่ม capex เช่นกัน เพราะตลาด AI ต้องการทั้ง memory bandwidth ระดับ HBM และ storage density ระดับ NAND

## Fab3 ที่ Kitakami คือสัญญาณ supply ระยะยาว

ในประกาศแยกอีกฉบับวันที่ **27 สิงหาคม 2026** Kioxia ระบุว่าเริ่ม site preparation สำหรับ **Fab3** โรงงานผลิตใหม่ที่ **Kitakami Plant** จังหวัดอิวาเตะ เพื่อขยายกำลังผลิต **BiCS FLASH** หรือ 3D flash memory ขั้นสูง

Fab3 จะสร้างบนพื้นที่ด้านใต้ของ Fab2 และตั้งเป้าเริ่ม operation ในปีงบประมาณ **2029** ส่วนรายละเอียด construction schedule และ equipment investment จะตัดสินตาม market trend และยังขึ้นกับการสนับสนุนจากรัฐบาล

Reuters รายงานว่า Kioxia CEO Hiroo Ota ระบุเงินลงทุนสำหรับโรงงาน Kitakami แห่งใหม่นี้ที่ประมาณ **1.8 ล้านล้านเยน** หรือราว **11.3 พันล้านดอลลาร์** และ Kioxia กำลังผลิต **10th-generation BiCS Flash** ที่ Kitakami ร่วมกับ Sandisk

## Memory เป็น national infrastructure

ข่าวนี้สะท้อนอีกเรื่องหนึ่ง: semiconductor capacity กลายเป็น infrastructure เชิงยุทธศาสตร์ของประเทศ ไม่ใช่แค่ธุรกิจเอกชน

ญี่ปุ่นต้องการฟื้นบทบาทใน supply chain ชิป ขณะที่สหรัฐและญี่ปุ่นต้องการความมั่นคงด้านเทคโนโลยีมากขึ้น Kioxia และ Sandisk จึงไม่ได้ประกาศแค่ขยายโรงงาน แต่เชื่อมแผนกับเป้าหมาย economic policy และความสัมพันธ์ญี่ปุ่น-สหรัฐ

สำหรับผู้ซื้อ cloud และ AI platform ความหมายคือ supply chain ของ AI จะแยกเป็นหลายชั้น:

- GPU และ accelerator
- HBM และ advanced packaging
- NAND flash และ enterprise SSD
- networking และ optical interconnect
- data center construction
- grid connection และ power purchase
- capital structure และ government support

ถ้าชั้นใดชั้นหนึ่งขยายไม่ทัน ราคาและเวลา deploy AI จะโดนกระทบทั้งระบบ

## ผลต่อ data center economics

NAND ไม่ได้แพงหรือเด่นแบบ GPU แต่มีผลต่อ economics ของ data center อย่างเงียบ ๆ เพราะ storage layer ต้องรับทั้ง throughput, durability, redundancy และ cost ต่อ TB ใน workload ที่ไม่หยุดโต

ถ้า supply flash memory ตึง:

- ราคา SSD enterprise อาจสูงขึ้น
- cloud storage และ AI storage tier อาจลดราคาช้าลง
- training pipeline อาจต้อง optimize data movement มากขึ้น
- inference service ที่ใช้ RAG หนักอาจเจอ storage cost เป็นตัวแปรใหญ่ขึ้น
- edge และ on-device AI อาจต้องคิด tradeoff ระหว่าง local storage กับ cloud sync

ดังนั้นแผนลงทุนของ Kioxia/Sandisk เป็นเหมือนการวางพื้นให้ AI infrastructure ไม่สะดุดเมื่อ GPU cluster และ agent workflow ขยายตัว

## สิ่งที่ต้องจับตาต่อ

ถึงตัวเลขลงทุนจะใหญ่ แต่ข่าวนี้ยังมีความไม่แน่นอนหลายด้าน:

- government support จะอนุมัติในรูปแบบใด
- demand AI storage จะโตต่อเนื่องถึงปี 2032 หรือไม่
- Fab3 จะเริ่ม operation ใน fiscal 2029 ได้ตามแผนแค่ไหน
- คู่แข่งจากเกาหลี ไต้หวัน จีน และสหรัฐจะตอบโต้อย่างไร
- NAND oversupply cycle จะกลับมากดราคาเมื่อกำลังผลิตใหม่เปิดหรือไม่
- AI workload จะเปลี่ยน architecture จนความต้องการ storage ต่างจากวันนี้หรือเปล่า

นี่คือธรรมชาติของ semiconductor capex: ตัดสินใจวันนี้ แต่รับผลจริงอีกหลายปี

## มุมมองของผม

ผมมองว่านี่เป็นข่าว Hardware / Infrastructure สำคัญของวันที่ **28 สิงหาคม 2026** เพราะมันเตือนว่า AI boom ไม่ได้รันบน GPU อย่างเดียว ทุกครั้งที่ model ใหญ่ขึ้น agent ทำงานมากขึ้น และ enterprise เก็บข้อมูลเพื่อ audit มากขึ้น memory กับ storage จะยิ่งกลายเป็นข้อจำกัด

Kioxia และ Sandisk กำลังวางเดิมพันว่าความต้องการ flash memory สำหรับ AI และโลก data-driven จะยังโตยาวถึงปี 2032 ถ้าถูกต้อง แผนนี้จะช่วยให้ญี่ปุ่นกลับมามีบทบาทมากขึ้นในชั้น infrastructure ที่สำคัญแต่ไม่ค่อยถูกพูดถึงของ AI supply chain

สรุปสั้น ๆ:
**Kioxia และ Sandisk ประกาศวันที่ 27 สิงหาคม 2026 ว่าจะลงทุนมากกว่า 31 พันล้านดอลลาร์ในญี่ปุ่นจนถึงปี 2032 พร้อมเตรียม Fab3 ที่ Kitakami ให้เริ่ม operation ใน fiscal 2029 ข่าวนี้ชี้ว่า NAND flash และ storage capacity กำลังกลายเป็นชั้นสำคัญของ AI infrastructure ไม่แพ้ GPU และ data center**
