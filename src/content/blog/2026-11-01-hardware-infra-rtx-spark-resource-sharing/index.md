NVIDIA ประกาศอัปเดต RTX Spark เมื่อวันที่ **28 ตุลาคม 2026** โดยเพิ่มทางเลือกให้ผู้ใช้จัดสรรทรัพยากร GPU ระหว่างแอปที่กำลังใช้งานกับ AI agent ที่ทำงานเบื้องหลัง ข่าว Hardware / Infrastructure ประจำวันที่ 1 พฤศจิกายนนี้จึงมองการจัดการภาระงานบนพีซีที่ใช้ทรัพยากรร่วมกัน

[ประกาศอย่างเป็นทางการ](https://blogs.nvidia.com/blog/local-ai-rtx-spark-laptops-updates-models-agents-games/) ระบุว่าเข้าถึงตัวเลือกได้ใน NVIDIA App ที่ System > Advanced และต้องเปิด hardware-accelerated GPU scheduling ใน Windows ก่อน ผู้ใช้เลือกให้ความสำคัญกับแอปด้านหน้าหรือเพิ่มทรัพยากรให้ agent ได้

## ซอฟต์แวร์ต้องตามความสามารถของเครื่องให้ทัน

RTX Spark รวม Grace CPU และ Blackwell RTX GPU พร้อมหน่วยความจำร่วมสูงสุด 128GB ตามข้อมูลผู้ผลิต อัปเดตเดียวกันกล่าวถึง Nemotron 3.5 Transcribe และโมเดล LFM3 สำหรับงาน AI บนเครื่อง โดยเวอร์ชัน quantized ของ Transcribe ยังระบุว่ากำลังจะตามมา

ในมุมผู้เขียน การแบ่ง GPU เป็นเรื่องที่ควรทดสอบด้วยงานจริง เช่น ประชุมวิดีโอขณะ agent ประมวลผลเอกสาร ตัวเลือกจัดลำดับความสำคัญไม่ได้ยืนยันว่าแอปทุกตัวจะเร็วขึ้น และบทความนี้ไม่มีผลทดสอบอิสระหรือการยืนยันวันขายในไทย

ภาพปกเป็นภาพ RTX Spark จากบทความ NVIDIA ที่ประกาศอัปเดตนี้
