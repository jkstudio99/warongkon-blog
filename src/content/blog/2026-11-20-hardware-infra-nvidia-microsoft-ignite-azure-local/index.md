NVIDIA เผยความคืบหน้าความร่วมมือกับ Microsoft เมื่อวันที่ 19 พฤศจิกายน 2026 ในช่วง Microsoft Ignite ครอบคลุมโครงสร้างพื้นฐาน Azure และการรัน AI ใกล้ข้อมูลขององค์กร ประเด็นใหม่อยู่ที่ทางเลือกติดตั้งและบริการพรีวิว ไม่ใช่ข่าววางขายเดสก์ท็อป RTX Spark ที่รายงานก่อนหน้านี้ [ประกาศ NVIDIA](https://blogs.nvidia.com/blog/microsoft-ignite-accelerated-computing-azure-windows-pcs/)

## เพิ่มทางเลือกสำหรับระบบภายในองค์กร

ประกาศระบุว่า Azure Local จะรองรับ NVIDIA RTX PRO 6000 Blackwell จากผู้ผลิตฮาร์ดแวร์พันธมิตร และขยายไปยัง Jetson Thor กับ Jetson Orin สำหรับงานอุตสาหกรรม เช่น machine vision และหุ่นยนต์ ส่วน Foundry Local เพิ่มการรองรับ Nemotron 3.5 เพื่อใช้งาน reasoning การเขียนโค้ด และเอเจนต์ที่เรียกเครื่องมือ

สำหรับ Azure บริษัทระบุว่าระบบ Vera Rubin NVL72 ทำงานอยู่ในดาต้าเซ็นเตอร์แล้ว และกำลังร่วมพัฒนา confidential computing ให้ครอบคลุมโครงสร้างพื้นฐานระดับแร็ก ข้อความเรื่องความร่วมมือนี้ยังไม่ใช่หลักฐานว่าความสามารถทั้งหมดเปิดใช้ทั่วไปแล้ว

## Direct Stream ยังมีขั้นตอนพรีวิว

Windows 365 Cloud PC ที่ใช้ GPU จะได้ความสามารถ Direct Stream ซึ่งบริษัทระบุว่ารองรับภาพ 4K สองสตรีมที่ 60 เฟรมต่อวินาที ขณะประกาศเปิดลงทะเบียน limited preview และวางแผน public preview ต้นปี 2027 จึงยังไม่ควรถือว่าองค์กรทุกแห่งเปิดใช้ได้ทันที

ภาพปกใช้ภาพ NVIDIA และ Microsoft จากประกาศวันที่ 19 พฤศจิกายนโดยตรง การเปิดบริการจริงต้องตรวจรุ่นฮาร์ดแวร์และสถานะบริการในแต่ละช่องทางอีกครั้ง
