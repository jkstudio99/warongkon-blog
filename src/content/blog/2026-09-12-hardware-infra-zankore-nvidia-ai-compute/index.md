ข่าว **Hardware / Infrastructure** สำหรับรอบวันที่ **12 กันยายน 2026** คือประกาศของ **Zankore** ในจาการ์ตาเมื่อวันที่ **9 กันยายน 2026** ว่าบริษัทกำลังสร้างโครงสร้างพื้นฐาน **NVIDIA AI Infrastructure** ระยะแรกขนาด **100 MW** เพื่อขยายบริการ AI cloud จากอินโดนีเซียไปยัง Southeast Asia

พร้อมกันนั้น Zankore ยังประกาศลงนามวงเงินกู้แบบ senior term loan facility สูงสุด **3.1 พันล้านดอลลาร์สหรัฐ** เพื่อสนับสนุนการซื้อและ deploy โครงสร้างพื้นฐาน GPU รุ่นใหม่

นี่เป็นข่าว infrastructure ที่สำคัญ เพราะมันบอกว่าตลาด AI compute กำลังเปลี่ยนจากการซื้อ server เป็นรอบ ๆ ไปสู่โมเดล financing แบบโครงการพลังงานหรือ data center ขนาดใหญ่

## GPU cloud ต้องใช้เงินทุนแบบ infrastructure

สองปีที่ผ่านมา AI cloud โตจากความต้องการ GPU สำหรับ training, fine-tuning และ inference แต่เมื่อ workload เริ่มใหญ่ขึ้น การสร้าง capacity ไม่ใช่เรื่องของ hardware procurement อย่างเดียว

โครงการระดับ 100 MW ต้องจัดการพร้อมกันหลายเรื่อง:

- GPU และ networking supply
- data center power และ cooling
- software layer สำหรับ training และ inference
- financing ที่สอดคล้องกับ demand ระยะยาว
- customer pipeline จาก enterprise, startup และสถาบันวิจัย
- partner ecosystem ที่ทำให้ capacity ถูกใช้งานจริง

Zankore จึงไม่ได้ประกาศแค่ซื้อ GPU แต่ประกาศโมเดลที่ผูกเทคโนโลยี เงินทุน และ demand เข้าด้วยกัน

## 100MW แรกคือฐานก่อนเป้าหมาย 1GW

ในประกาศ Zankore ระบุว่า platform จะให้บริการ high-performance GPU clusters สำหรับงาน AI training, fine-tuning, large-scale inference และ agentic AI application

เป้าหมายระยะยาวของบริษัทคือการสร้าง capacity สูงสุด **1 GW** ของ NVIDIA AI computing ขณะที่ capacity เริ่มต้นประมาณ **200 MW** ถูกวางไว้ในครึ่งแรกของปี **2027** ตามแผนที่ประกาศตอนเปิดตัวบริษัทเมื่อวันที่ **6 สิงหาคม 2026**

การเริ่มที่ 100 MW จึงไม่ใช่ pilot เล็ก ๆ แต่เป็นเฟสแรกของ regional compute platform ที่ต้องพิสูจน์ว่าอินโดนีเซียสามารถเป็นฐาน AI infrastructure สำหรับ SEA ได้จริง

## ทำไมอินโดนีเซียจึงสำคัญต่อ AI infrastructure ของภูมิภาค

Southeast Asia มีความต้องการ AI เพิ่มขึ้นเร็ว แต่ compute capacity ยังมักกระจุกอยู่ในบาง hub เช่น สิงคโปร์หรือ cloud region ของ hyperscaler

อินโดนีเซียมีปัจจัยที่น่าสนใจหลายด้าน:

- ตลาดผู้ใช้ขนาดใหญ่
- enterprise และ digital platform จำนวนมาก
- data sovereignty และ local latency เป็นเรื่องสำคัญขึ้น
- telco มีฐานลูกค้าและ network distribution
- รัฐและอุตสาหกรรมต้องการเพิ่มผลิตภาพด้วย AI

ถ้า AI workload ถูก deploy ใกล้ข้อมูลและผู้ใช้ในประเทศมากขึ้น องค์กรท้องถิ่นจะไม่ได้เป็นแค่ผู้ซื้อ API จากต่างประเทศ แต่มีโอกาสสร้าง model, application และบริการของตัวเองบน infrastructure ในภูมิภาค

## Financing รอบนี้บอกว่า AI compute กลายเป็นสินทรัพย์ระยะยาว

วงเงินกู้ **3.1 พันล้านดอลลาร์** มีความหมายมากกว่าตัวเลขใหญ่

โครงสร้าง senior term loan และการมีสถาบันการเงินระดับภูมิภาคและนานาชาติเข้าร่วมทำให้เห็นว่า GPU infrastructure เริ่มถูกมองคล้าย asset class ใหม่ที่ finance sector ต้องเรียนรู้

Data Center Dynamics รายงานว่า financing นี้สนับสนุน first phase ของ AI cloud buildout และจะใช้พัฒนา capacity ของ Zankore โดยมี Citi เป็น debt adviser

ประเด็นที่น่าจับตาคือ AI compute มีความเสี่ยงต่างจาก data center แบบเดิม:

- GPU generation เปลี่ยนเร็ว
- utilization ต้องสูงพอให้ economics คุ้ม
- software stack เป็นตัวกำหนด lock-in และ margin
- power contract ต้องมั่นคง
- ลูกค้าอาจเปลี่ยน workload ระหว่าง training และ inference
- ราคาต่อ token และราคาต่อ GPU-hour อาจลดเร็ว

ถ้าสถาบันการเงินเริ่ม underwrite ความเสี่ยงเหล่านี้ได้ดีขึ้น โครงการ AI factory ในเอเชียอาจเกิดเร็วขึ้นมาก

## NVIDIA ecosystem ยังเป็นแกนกลาง

Zankore วาง platform บน full-stack AI computing technologies ของ **NVIDIA** ซึ่งสะท้อนภาพใหญ่ของตลาดปี 2026: ผู้เล่น AI cloud ใหม่จำนวนมากยังต้องอาศัย ecosystem ของ NVIDIA ตั้งแต่ GPU, networking, software library ไปจนถึง reference architecture

การแข่งขันจึงไม่ได้อยู่ที่ใครมี chip เท่านั้น แต่อยู่ที่ใครรวม stack ให้ลูกค้าใช้งาน production ได้เร็วกว่า

สำหรับ startup และ developer ใน SEA สิ่งที่น่าสนใจคือถ้า regional GPU cloud มี capacity จริงมากขึ้น ต้นทุนและ latency ของการทดลอง model อาจดีขึ้น โดยเฉพาะ use case ที่ต้องพึ่ง data ในประเทศหรือมีเงื่อนไขด้าน compliance

## สรุป

ประกาศของ **Zankore** เรื่อง AI compute **100 MW** กับ **NVIDIA** และวงเงินกู้สูงสุด **3.1 พันล้านดอลลาร์** เป็นข่าว Hardware / Infrastructure ที่ชี้ว่า AI cloud กำลังถูกสร้างด้วยภาษาของ infrastructure finance

จากเดิมที่ตลาดพูดถึง GPU shortage และ model training cluster ตอนนี้คำถามใหญ่ขึ้นคือใครจะหาเงินทุน พลังงาน cooling software และลูกค้าให้พอสำหรับ platform ระดับ regional

ถ้า Zankore ทำตาม roadmap ได้ อินโดนีเซียอาจกลายเป็นหนึ่งในฐาน AI compute สำคัญของ Southeast Asia และทำให้การแข่งขัน GPU cloud ในภูมิภาคจริงจังขึ้นมากในปี 2027
