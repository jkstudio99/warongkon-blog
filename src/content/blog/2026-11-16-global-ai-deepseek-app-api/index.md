DeepSeek เปิดเครื่องมือจากแอปให้ผู้พัฒนาเรียกผ่าน API เมื่อวันที่ 13 พฤศจิกายน 2026 แอปที่ใช้ V4.1-Flash ผ่านชื่อโมเดล `deepseek-flash` สามารถเปิดให้โมเดลค้นเว็บ อ่านลิงก์ และใช้ข้อมูลจากไฟล์ประกอบคำตอบได้ โดย DeepSeek จัดการการเรียกเครื่องมือและนำผลเข้าไปในบริบทของบทสนทนาฝั่งเซิร์ฟเวอร์ [บันทึกการเปลี่ยนแปลงของ DeepSeek](https://api-docs.deepseek.com/updates/) · [ประกาศเปิดตัว](https://api-docs.deepseek.com/news/news261113/)

## เครื่องมือในแชตกับ API ที่เรียกแยก

เมื่อเปิดเครื่องมือค้นเว็บร่วมกับโหมดคิด โมเดลสามารถค้นหาและอ่านหน้าเว็บหลายรอบระหว่างทำงาน ส่วนการป้อนไฟล์รองรับ PDF เอกสาร Office และรูปภาพ โดยระบบแปลงเนื้อหาให้อยู่ในรูปที่ใช้ตอบในบทสนทนาได้ หากต้องการนำผลไปใช้ในขั้นตอนอื่นโดยไม่ผ่านแชต นักพัฒนาสามารถเรียก API สำหรับค้นหาเว็บ ดึงหน้าเว็บ แปลงภาพเป็นข้อความ ถอดเสียง หรือสร้างเสียงจากข้อความแยกได้ [คู่มือสร้างแชตบอตของ DeepSeek](https://api-docs.deepseek.com/guides/build_a_chatbot)

DeepSeek ระบุว่าค่าเครื่องมือคิดเพิ่มจากค่าโทเคน และกำหนดให้แอปที่ให้บริการสาธารณะเปิดการตรวจความปลอดภัยของโมเดล นักพัฒนายังต้องดูแลการกลั่นกรองเนื้อหาในบริการของตนเอง บริษัทเผยแพร่ [โค้ดตัวอย่างแชต](https://github.com/deepseek-ai/chat-demo) ที่ใช้ API ชุดเดียวกันด้วย

ภาพปกเป็นตารางค่าเครื่องมือจาก [ประกาศเปิดตัวของ DeepSeek](https://api-docs.deepseek.com/news/news261113/)
