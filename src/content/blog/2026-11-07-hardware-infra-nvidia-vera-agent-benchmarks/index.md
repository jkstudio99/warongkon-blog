NVIDIA [เผยรายงานผลทดสอบ Vera CPU เมื่อวันที่ 5 พฤศจิกายน 2026](https://blogs.nvidia.com/blog/vera-cpu-highest-throughput-fastest-agents/) โดยเน้นงานที่ AI agent ต้องสลับจากการคิดบน GPU ไปค้นข้อมูล รันโค้ด และทำงานบน CPU ข่าว Hardware / Infrastructure ประจำวันที่ 7 พฤศจิกายนนี้จึงเกี่ยวกับข้อมูลประสิทธิภาพที่เผยแพร่ใหม่ ไม่ใช่การประกาศเปิดตัวชิปครั้งแรก

## ประสิทธิภาพภายใต้งบพลังงาน

บริษัทใช้การเปรียบเทียบศูนย์ข้อมูลขนาด 100 เมกะวัตต์ และอ้างว่า Vera รองรับจำนวน agent ต่อวัตต์ได้มากกว่า CPU x86 ที่เร็วที่สุดในการเปรียบเทียบ 1.6 เท่า อีกการเปรียบเทียบกับ x86 ที่ประหยัดพลังงานที่สุดในชุดทดสอบ บริษัทระบุความเร็ว agent สูงกว่าสองเท่า ตัวเลขเหล่านี้เป็นผลที่ผู้ขายนำเสนอ ไม่ใช่ข้อสรุปว่าเร็วกว่าทุกระบบในทุกงาน

## ผลของพันธมิตรยังต้องอ่านตาม workload

NVIDIA รายงานว่า Perplexity ทดสอบงาน agentic coding ได้เร็วขึ้น 1.5 เท่าและวางแผนนำไปใช้ในระบบ production ขณะที่ Modal รายงาน throughput ของ sandbox ต่อคอร์เพิ่มสูงสุดสองเท่าเมื่อเทียบกับฮาร์ดแวร์ x86 ที่ใช้ทดสอบ การวางแผนใช้งานของ Perplexity จึงควรแยกจากการติดตั้งเสร็จแล้ว

ในมุมผู้ดูแลโครงสร้างพื้นฐาน ข่าวนี้ชี้ว่าคอขวดของ agent ไม่ได้จบที่ GPU การประเมินระบบจริงยังต้องใช้ชุดงาน จำนวน sandbox พร้อมกัน และข้อจำกัดพลังงานของตนเอง ผลจากชุดทดสอบต่างกันไม่ควรถูกรวมเป็นค่าเร่งความเร็วเดียว
