ข่าว **Hardware / Infrastructure** สำหรับรอบวันที่ **27 สิงหาคม 2026** คือผลประกอบการไตรมาสสองปีงบประมาณ 2027 ของ **NVIDIA** ที่ทำให้ภาพการลงทุน AI infrastructure ชัดขึ้นอีกระดับ

NVIDIA เผยแพร่ผลประกอบการเมื่อวันที่ **26 สิงหาคม 2026** ตามเวลาสหรัฐ โดยรายงานไตรมาสที่สิ้นสุดวันที่ **26 กรกฎาคม 2026** บริษัทมีรายได้รวม **96.2 พันล้านดอลลาร์** เพิ่มขึ้น **18%** จากไตรมาสก่อน และเพิ่มขึ้น **106%** จากปีก่อน ส่วนธุรกิจ **Data Center** ทำรายได้ **89.0 พันล้านดอลลาร์** เพิ่มขึ้น **117%** จากปีก่อน

เมื่อถึงรอบข่าวเอเชียวันที่ **27 สิงหาคม 2026** AP รายงานว่าผลประกอบการนี้สูงกว่าคาดของ Wall Street และสะท้อน demand จากชิป AI ที่ยังแรงมาก ข่าวนี้จึงเป็นตัวเลขสำคัญกว่าการเปิดตัว hardware รุ่นใดรุ่นหนึ่ง เพราะมันบอกว่า AI infrastructure กลายเป็นงบลงทุนหลักของบริษัทเทคโนโลยีทั่วโลกไปแล้ว

## ตัวเลขที่ควรจำ

ข้อมูลจาก NVIDIA มีหลายจุดที่ควรจับตา:

- รายได้รวมไตรมาสสอง FY2027 อยู่ที่ **96.2 พันล้านดอลลาร์**
- Data Center revenue อยู่ที่ **89.0 พันล้านดอลลาร์**
- Data Center โต **18%** จากไตรมาสก่อน และ **117%** จากปีก่อน
- GAAP และ non-GAAP gross margin อยู่ที่ **75.0%**
- กำไรต่อหุ้นแบบ diluted อยู่ที่ **2.46 ดอลลาร์** ตาม GAAP
- company outlook สำหรับไตรมาสสาม FY2027 คือรายได้ **108.0 พันล้านดอลลาร์** บวกลบ 2%
- NVIDIA ระบุว่า outlook ดังกล่าวไม่รวม Data Center compute revenue จากจีน

สำหรับ infrastructure market ตัวเลข Data Center สำคัญที่สุด เพราะรายได้นี้คือภาพรวมของ GPU, networking, platform และ ecosystem รอบ AI factory ที่ hyperscaler, neocloud, frontier lab และ enterprise กำลังแย่ง capacity กัน

## Compute กลายเป็นรายได้ ไม่ใช่แค่ต้นทุน

คำอธิบายของ Jensen Huang ในข่าว NVIDIA สื่อสารชัดว่า compute ไม่ได้เป็นแค่ค่าใช้จ่ายหลังบ้านอีกต่อไป แต่เป็นสิ่งที่เปลี่ยนเป็น revenue ได้โดยตรง เมื่อ model lab, enterprise และ startup ต้องการ token throughput เพื่อขายสินค้า AI ของตัวเอง

นี่คือเหตุผลที่ตลาด AI infrastructure ไม่เหมือน server cycle ปกติ:

- demand ไม่ได้มาจากการ refresh hardware รอบเดิมเท่านั้น
- model training และ inference สร้าง workload ใหม่ตลอดเวลา
- AI agent เพิ่มจำนวน task ที่ต้องใช้ compute
- open model ecosystem ทำให้ผู้เล่นนอก hyperscaler ใช้ GPU มากขึ้น
- physical AI และ robotics เริ่มดึง compute ไปที่โลก edge
- sovereign AI ทำให้หลายประเทศต้องสร้าง capacity ในประเทศ

ถ้าคอมพิวต์เป็นวัตถุดิบของรายได้ AI บริษัทที่มี supply chain และ platform ที่ควบคุมได้จะมีอำนาจสูงมาก

## Vera Rubin เริ่มเป็น production signal

ในส่วน Data Center NVIDIA ระบุว่า **Vera Rubin platform** กำลัง ramp เข้าสู่ full production และมี rack ทำงานอยู่กับ partner เช่น **CoreWeave**, **Google Cloud**, **Microsoft Azure**, **Oracle Cloud Infrastructure** และ **Nebius**

นี่เป็นข่าว infrastructure ที่ต้องอ่านควบคู่กับผลประกอบการ เพราะ growth ของ NVIDIA ไม่ได้ขึ้นกับ Blackwell เพียงรุ่นเดียวอีกต่อไป ตลาดกำลังมองไปที่ lifecycle ถัดไปของ rack-scale AI:

- GPU และ CPU ที่ออกแบบให้ทำงานเป็น platform
- memory bandwidth และ interconnect ที่ต้อง scale พร้อมกัน
- switch และ optics ที่รองรับ cluster ขนาดใหญ่
- liquid cooling และ power envelope ที่สูงขึ้น
- software stack ที่ช่วยให้ลูกค้าใช้งาน hardware ได้เต็มประสิทธิภาพ

Vera Rubin จึงไม่ใช่แค่ product roadmap แต่เป็นการบอกลูกค้าว่า capacity รุ่นถัดไปเริ่มเข้าใกล้ production แล้ว

## Network fabric กลายเป็นจุดขายหลัก

NVIDIA ยังพูดถึง **Spectrum-6 switch systems** และ co-packaged optics ในบริบท Vera Rubin ด้วย ประเด็นนี้สำคัญมาก เพราะเมื่อ cluster ใหญ่ขึ้น bottleneck จะย้ายจาก GPU เดี่ยวไปอยู่ที่การสื่อสารระหว่าง node

AI factory ที่มี GPU ราคาแพงจำนวนมากจะเสียมูลค่าทันทีถ้า network fabric ทำให้ GPU รอข้อมูลนานเกินไป ดังนั้น infrastructure buyer ปี 2026 ต้องคิดทั้งระบบ:

- accelerator performance
- east-west traffic ใน cluster
- congestion control
- storage path
- telemetry และ observability
- thermal design
- power distribution
- fault isolation และ serviceability

ข่าวผลประกอบการนี้จึงยืนยันว่าตลาดกำลังซื้อ "AI platform" มากกว่าซื้อ GPU card แยกชิ้น

## Supply และจีนยังเป็น risk ใหญ่

แม้ตัวเลขออกมาแข็งแรงมาก NVIDIA ยังระบุใน outlook ว่าไม่ได้สมมติ Data Center compute revenue จากจีนไว้ ประโยคนี้เป็นสัญญาณสำคัญ เพราะ export control, geopolitics และ supply chain ยังเป็นตัวแปรที่ทำให้รายได้ AI infrastructure ผันผวนได้

อีกด้านหนึ่ง AP และสื่อการเงินหลายแห่งชี้ว่าตลาดยังตั้งคำถามเรื่องความยั่งยืนของการลงทุน AI ขนาดใหญ่ ไม่ว่าจะเป็นผลตอบแทนจาก AI application, ต้นทุน data center, พลังงาน, น้ำ, memory supply หรือความเสี่ยงจากลูกค้ารายใหญ่ที่เริ่มพัฒนาชิปของตัวเอง

ดังนั้นข่าวนี้มีสองหน้า:

- หน้าบวกคือ demand ยังแรงและตัวเลขเหนือคาด
- หน้าระวังคือ AI capex ต้องพิสูจน์ว่าเปลี่ยนเป็น cash flow ของลูกค้าได้จริง

## ผลต่อ hyperscaler และ enterprise

สำหรับ hyperscaler ตัวเลขนี้ยืนยันว่า race ด้าน AI capacity ยังไม่ชะลอ ทุกบริษัทต้องมี GPU cluster ให้พอสำหรับ model training, inference, enterprise customer และ internal product

สำหรับ enterprise ข่าวนี้มีผลทางอ้อมแต่สำคัญ:

- cloud AI price อาจยังไม่ลดเร็วถ้า demand เหนือ supply
- vendor lock-in กับ platform AI จะเป็นประเด็นจัดซื้อ
- workload placement ระหว่าง public cloud, neocloud และ private AI cluster ต้องคิดละเอียดขึ้น
- governance ของข้อมูลและ cost ต่อ task ต้องเข้มขึ้น
- ทีม infrastructure ต้องเข้าใจ power, cooling และ networking มากขึ้น แม้ไม่ได้สร้าง data center เอง

AI strategy ในปี 2026 จึงไม่ใช่แค่เลือก model แต่ต้องเข้าใจเศรษฐศาสตร์ของ compute ที่อยู่ใต้ model ด้วย

## สิ่งที่ต้องจับตาต่อ

หลังผลประกอบการนี้ สิ่งที่ควรติดตามคือ:

- Q3 revenue จะเข้าใกล้ guidance **108.0 พันล้านดอลลาร์** แค่ไหน
- Vera Rubin production ramp จะเจอ supply bottleneck ตรงไหน
- memory cost จะกด margin หรือไม่
- hyperscaler จะซื้อ NVIDIA ต่อเนื่องแม้พัฒนาชิปเองหรือเปล่า
- export control จีนจะกระทบ Data Center revenue แค่ไหน
- AI application ฝั่งลูกค้าจะสร้าง ROI พอรองรับ capex ระดับนี้หรือไม่

ถ้าคำตอบยังเป็นบวก NVIDIA จะยังเป็นจุดศูนย์กลางของ AI infrastructure wave ต่อไป แต่ถ้า ROI ฝั่ง application ช้ากว่าที่ตลาดหวัง ความผันผวนของกลุ่ม hardware จะสูงขึ้นทันที

ตัวเลข Data Center **89.0 พันล้านดอลลาร์** ในหนึ่งไตรมาสทำให้คำถามสำคัญเปลี่ยนจาก "ใครมี GPU" เป็น "ใครใช้ compute ให้สร้างรายได้ได้จริง" และนั่นจะเป็นโจทย์ใหญ่ของทั้ง model lab, cloud provider, enterprise และประเทศที่กำลังลงทุน sovereign AI
